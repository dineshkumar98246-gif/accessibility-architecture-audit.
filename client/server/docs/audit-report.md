# Accessibility Audit Report

## Website
https://www.mtcet.in/

## Audit Tool
Google PageSpeed Insights (Lighthouse)

## Device
Mobile

## Accessibility Score
93/100

## Finding 1: Insufficient Color Contrast
Evidence: Lighthouse flagged insufficient contrast between background and foreground colors.
Recommended fix: Adjust colors to meet WCAG contrast requirements.

## Finding 2: Heading Order
Evidence: Lighthouse flagged heading elements that do not follow sequential order.
Recommended fix: Organize headings into a logical hierarchy.
